## Como ler cada sessão

Toda sessão tem os dez itens pedidos. Para não repetir texto 200 vezes, os itens 5, 6, 7 e 9 seguem a **política fixa** abaixo e cada aula detalha o resto:

| Item | Onde está |
|---|---|
| 1. Código | coluna **Cód.** |
| 2. Disciplina e assunto | cabeçalho de cada tabela |
| 3. Objetivo de aprendizagem | coluna **Objetivo** |
| 4. Conteúdo específico | coluna **Unidades** |
| 5. Material teórico | `aulas/<Cód>-<slug>.md` (Nível A) — ver Produto 5 |
| 6. Videoaula | termos de busca por disciplina em `06-biblioteca-de-fontes.md`; aula específica quando verificada |
| 7. O que anotar | seção **ANOTE NO CADERNO** da aula (Nível B), no caderno indicado |
| 8. Quantidade de questões | coluna **Q** |
| 9. Revisões | D+1, D+7 e D+30 automáticas, na data real do calendário (Produto 3) |
| 10. Critério de conclusão | coluna **Conclusão** |

**Regra de conclusão:** a sessão só é concluída quando o critério da última coluna é cumprido *e* as questões são corrigidas com registro dos erros. Assistir aula não conclui sessão.
